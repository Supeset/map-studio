## Project Overview

Map Studio (万物分享) — a web-based map toolbox built with Nuxt (Vue 3 + TypeScript). Integrates multiple geo tools: GeoJSON drawing, coordinate conversion (WGS84/GCJ02/BD09), astronomy calculations, and rocket launch site visualization. Deployed on Netlify as SPA (SSR disabled).
